# ผลตรวจการสมัครครูและจัดการนักเรียน วันที่ 8 กันยายน 2569

เพิ่มปุ่มสมัครครูด้วย Google และการตรวจสอบสถานะอนุมัติ เพิ่มนักเรียนพร้อมชั้น/ห้องและเลขที่ใน transaction เดียว คำนำหน้าเป็น dropdown ดาวน์โหลดแบบฟอร์ม Excel พร้อมชีตตัวอย่าง/คำแนะนำ และเอาช่องเลขห้องออกจากฟอร์มห้องเรียน

| การตรวจ | ผล |
| --- | --- |
| `npm run lint` | PASS |
| `npm run typecheck` | PASS |
| `npm test` | PASS 46 tests |
| Firebase database suite (`vitest run --config vitest.firebase.config.ts` ใน Emulator) | PASS 23 tests / 3 files |
| Browser tests | ตรวจครบ 18 กรณี โดยรันซ้ำเฉพาะกรณีที่แก้ตามรายละเอียดด้านล่าง |
| `npm run build` | PASS Next.js 16.3.4 |

Browser รอบแรกตรวจระบบคะแนน การประเมิน Submit/Approve/Lock และ Export ผ่าน แต่พบข้อผิดพลาด 3 กรณีใน flow ใหม่ จึงแก้การเลือกโรงเรียนแรกให้เรียงตามวันที่สร้าง แก้ข้อความ error เลขที่ซ้ำ และให้ Audit การดาวน์โหลดแบบฟอร์มทำงานได้โดยไม่ต้องระบุรายวิชา

รอบถัดมาทดสอบทุกกรณียกเว้น flow คะแนนที่ผ่านแล้ว: ผ่าน 16 กรณี และพบ selector ของชุดทดสอบสมัครครูเลือก heading ได้สองตัว หลังระบุชื่อ heading ให้ชัดเจน รันทดสอบสมัครครูซ้ำผ่านอีก 1 กรณี การรันสุดท้ายของแต่ละกรณีจึงผ่านทั้งหมด ไม่ได้อ้างว่าเป็นผลคำสั่ง E2E รอบเดียวทั้ง 18 กรณี

ทดสอบ Google popup กับ Firebase Auth Emulator → สร้าง profile → หน้ารออนุมัติ → ปฏิเสธการเข้าหน้าคะแนน → Admin เห็นบัญชีและอนุมัติ → ครูกดตรวจสถานะแล้วเข้า Dashboard ได้ ทดสอบหน้าจอ 375–1440px

ทดสอบเพิ่มนักเรียนจากฟอร์มพร้อมห้อง เลขที่ และคำนำหน้า ข้อมูลแสดงในตารางจริง ทดสอบเลขที่ซ้ำแล้วไม่มีประวัตินักเรียนค้าง ทดสอบเพิ่มห้องโดยไม่กรอกเลขห้อง ดาวน์โหลด Excel จริง ตรวจชีตตัวอย่าง กรอกชีตแรก อัปโหลด Preview และยืนยันนำเข้าได้ 1 คน โดยข้อมูลตัวอย่างไม่ถูกนำเข้า

ข้อมูลทดสอบทั้งหมดอยู่ใน Firebase Emulator ไม่มีการเพิ่มบัญชีหรือนักเรียนทดสอบใน Firebase production เว็บ local เปิดที่ `http://localhost:3000` โดยใช้ configuration เดิมของผู้ใช้
