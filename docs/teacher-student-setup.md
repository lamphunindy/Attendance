# สมัครครูและเพิ่มนักเรียน

## ให้ครูสมัครเอง

ครูเปิด `/login` แล้วกด **สร้างบัญชีครูด้วย Google** เลือกอีเมล Google ของตนเอง ระบบสร้างประวัติและแสดงหน้ารออนุมัติ ผู้ดูแลเปิด **จัดการครู** ตรวจชื่อ/อีเมลแล้วกด **อนุมัติ** ครูกด **ตรวจสอบการอนุมัติ** เพื่อเข้า Dashboard ได้ จากนั้นผู้ดูแลมอบหมายห้องและวิชาที่ครูสอน

หากผู้ดูแลเพิ่มอีเมลใน **เชิญครูด้วยอีเมล Google** ไว้แล้ว ครูต้องสมัครด้วยอีเมลเดียวกัน คำเชิญที่ยังไม่หมดอายุจะให้สิทธิ์ตามที่ผู้ดูแลกำหนด ระบบไม่ส่งอีเมลเชิญอัตโนมัติ บัญชีที่ไม่มีคำเชิญยังไม่มีสิทธิ์อ่านคะแนนหรือข้อมูลนักเรียน

## เพิ่มนักเรียนทีละคน

ไปที่ **นักเรียน → เพิ่มนักเรียน** เลือก **ชั้น / ห้องเรียน** ซึ่งแสดงปีการศึกษากำกับ กรอก **เลขที่**, รหัสนักเรียน, เลือกคำนำหน้าจากดรอปดาวน์ แล้วกรอกชื่อ/นามสกุลและชื่อเล่น กดบันทึก ระบบสร้างประวัติและการลงทะเบียนเข้าห้องใน transaction เดียว หากเลขที่หรือรหัสซ้ำ จะไม่เพิ่มนักเรียนค้างไว้ครึ่งรายการ

รายการนักเรียนแสดงชั้น/ห้องและเลขที่แล้ว หากต้องย้ายห้องให้ใช้ **จัดห้อง / ย้ายนักเรียน** เพื่อรักษาประวัติและผลการเรียนเดิม

## นำเข้าจาก Excel

หน้า **นักเรียน** มีปุ่ม **ดาวน์โหลดแบบฟอร์มและตัวอย่าง Excel** และ **นำเข้านักเรียน Excel** ไฟล์ดาวน์โหลดมี 3 ชีต:

1. **นักเรียน**: กรอกข้อมูลจริงในชีตนี้ ระบบอ่านเฉพาะชีตแรก
2. **ตัวอย่าง**: ข้อมูลสมมุติแสดงวิธีกรอก ไม่ถูกนำเข้า
3. **วิธีกรอก**: คำแนะนำและความหมายของข้อมูล

คอลัมน์ต้องเรียงตามเดิม: `student_code`, `student_number`, `prefix`, `first_name`, `last_name`, `nickname` โดย `student_number` คือเลขที่ในห้อง ส่วนชั้น/ห้องให้เลือกจากฟอร์มอัปโหลด นักเรียนทุกแถวจะเข้าห้องเดียวกัน ไม่ต้องใส่ชื่อห้องใน Excel

เลือกไฟล์ `.xlsx` ไม่เกิน 3 MB และไม่เกิน 500 คน กด **ตรวจสอบและแสดงตัวอย่าง** แก้ error ทุกแถวก่อนกด **ยืนยันนำเข้าทั้งหมด**
